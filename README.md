# Patient Management System

A microservices-based **Patient Management System** built using **Java and Spring Boot**. The system is designed using modern backend architecture principles including microservices, gRPC communication, Kafka messaging, and PostgreSQL databases.

The project demonstrates how multiple services interact together in a distributed environment.

---

# Architecture Overview

The system consists of the following services:

* Patient Service
* Billing Service
* Notification Service
* Auth Service
* Kafka (Messaging Broker)
* PostgreSQL Databases

Service communication includes:

* REST APIs
* gRPC communication between services
* Kafka event-driven messaging
